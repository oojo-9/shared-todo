## 2026-10-09 (금) · 버그 수정 3건

### 21. 🐞 스크롤·중복 등록·완료 되돌아감 — 14:44 (`d4db9e9`)

**① 버튼을 누르면 스크롤이 맨 위로 올라가던 문제**
- 증상: 목록을 아래로 내린 뒤 체크 버튼을 누르면 맨 위로 돌아가서 엉뚱한 항목을 누르게 됨
- 원인: 버튼을 누를 때마다 화면을 다시 그리는데, 스크롤 위치를 화면 전체 하나만 기억했음. 친구가 2명 이상이면 공유 보기가 칸으로 나뉘고 "나" 칸 안에서 따로 스크롤되는데, 이 칸의 위치는 기억하지 않았음. 친구가 체크해서 실시간 반영될 때도 똑같이 올라갔음
- 수정: 스크롤되는 칸(공유 보기 각 칸, 통계 목록, 팝업)마다 위치를 기억했다가 되돌림

**② 할 일·카테고리가 두 개씩 등록되던 문제**
- 증상: 한 번 추가했는데 같은 항목이 두 개 생김
- 원인: "추가"를 눌러도 저장이 끝날 때까지 팝업이 그대로 떠 있어서, 인터넷이 느릴 때 한 번 더 누르면 그대로 두 번 저장됐음
- 수정: 누르는 즉시 팝업을 닫고, 저장 중에는 같은 버튼이 다시 실행되지 않게 막음 (할 일 추가, 반복 일정 추가, 카테고리 추가, 상대 요청)

**③ 완료를 눌렀는데 이전 상태로 돌아가던 문제**
- 증상: 완료로 바꿨는데 가끔 "진행중"이나 "할 일 전"으로 되돌아감
- 원인: 완료하려면 두 번 눌러야 하는데, 빠르게 누르면 저장 요청 두 개가 동시에 나가서 서버에 순서가 뒤바뀌어 도착하는 경우가 있었음. 저장이 끝나기 전에 불러온 옛 데이터가 화면을 덮어쓰기도 했음
- 수정: 체크는 누른 순서대로 하나씩 저장하고, 저장 중인 항목은 방금 누른 상태를 유지함
